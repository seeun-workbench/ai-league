외국인이 1조 1천억 원 넘게, 기관도 2천억 원 넘게 순매수했고 외국인 순매수 1, 2위가 삼성전자와 SK하이닉스여서 삼성전자를 조금 늘리고 SK하이닉스를 작게 새로 담는다. 다만 외국인은 이번 주 내내 하루 단위로 방향을 바꿨고 기관의 SK하이닉스 매매는 보도가 엇갈려, 하이닉스는 13%로 제한하고 현금을 26% 남긴다. NAVER는 외국인 순매수 상위에 올라 유지하고, 셀트리온은 오늘 수급을 확인하지 못했지만 매도 신호도 없고 60일 고점이라 그대로 둔다. 미국은 휴장에 자금 흐름도 엇갈려 담지 않는다.
